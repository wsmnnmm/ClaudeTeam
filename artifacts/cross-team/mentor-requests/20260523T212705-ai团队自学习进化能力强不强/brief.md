# 请教 AI 刘小排：我的 AI 团队自学习进化能力强不强

## 背景

老板搭建了 ClaudeTeam 团队基座，并接入飞书 CLI、飞书机器人、飞书群、Hermes 微信助理、老板驾驶舱。当前有四个团队：

- Product Lab：产品出海 / 产品机会 / 增长实验。
- WorkAssistant：公司工作分身 / 页面还原 / 业务梳理 / 接口联调。
- TODO002：学习教练 / AI 导师网关。
- WebsiteChuhai：出海军师团队。

老板的目标不是让 AI 员工偶尔完成单次任务，而是让团队能自我纠错、自我学习、自我进化，最终减少老板在上班工作层面的时间浪费，把时间释放给 AI 产品出海、AI 编程学习、方向/机会/需求层面的判断。

## 近期真实进化证据

1. 老板指出“AI 导师有两个独立入口”，团队随后新增单导师问题门禁：单导师可见 prompt 不允许出现另一个导师名字，也不允许“共同回答”。
2. 老板指出“问导师上传错图”，团队补了图片证据门禁：每张图片必须有 `--image-caption`；旧图/图文不匹配直接 blocker。
3. 老板指出“AI 员工只发路径，人看不到内容”，团队新增路径型交付门禁：老板可见回复必须先给摘要、核心结论、下一步，路径只做证据索引。
4. 老板指出“飞书群里应该一句话问刘小排/问导师”，团队新增 `claudeteam mentor-request` 通用入口，四个团队 manager 都已重新注入身份规则。
5. 老板指出“老板驾驶舱 Base 太重，微信简报也不是人看的”，Hermes 已改成微信可回复行动卡，例如老板可以回“1 重核 / 2 接入先审计”，不必打开多维表格。
6. 每次修复都配了单元测试或真实链路验证：ClaudeTeam 当前全量测试 `1192 passed, 0 failed`；TODO002 云上导师链路可跑通；Hermes 老板简报测试 `7 passed`。

## 仍然暴露的问题

1. 很多进化来自老板纠偏，不是团队主动发现。老板仍然经常要指出“这个不是人看的”“你想当然了”“你发错图了”。
2. 团队能补规则，但还不稳定地在第一次交付时做到人类可消费；容易把内部路径、后台字段、Base 操作话术直接发给老板。
3. 健康检查里经常出现 worker 心跳陈旧，需要 manager live health 回执；这说明长期自巡检还没有完全闭环。
4. AI 导师链路已经更稳，但仍然需要机器门禁兜住 prompt 污染、错图污染、单导师边界污染。
5. Hermes 微信侧刚开始从“只读简报”升级为“可回复操作”，还需要真实微信交互验证和更多任务修改能力。

## 想请你判断

请从 AI 产品和执行系统视角判断：

1. 这套 AI 团队目前的自学习进化能力算强、中等，还是弱？
2. 哪些能力已经像“自学习系统”，哪些还只是“老板纠偏后的补丁系统”？
3. 下一轮最小动作应该怎么做，才能让团队少靠老板纠偏，多靠自己发现问题、修规则、跑验证、沉淀 SOP？
4. 应该用哪些指标衡量“AI 团队真的在进化”，而不是只是文件越来越多、规则越来越复杂？
5. 哪些事情必须人类老板继续做，哪些应该交给团队自动做？

## 期望输出

请给出 3-5 个最小动作，每个动作包含：

- Owner
- 完成证据
- 验收指标
- 不做什么

请尽量给出可以落成机器门禁、巡检任务、团队 SOP 或老板微信控制台交互的建议。
