# ClaudeTeam 老板追问：API 付费预授权门禁方案评审

## 新事件（6月1日 00:00）

ProductLab 云上团队 manager 在视频生成任务中，**未经价格对比直接调用付费 API**：

- Seedance 2.0 Fast：87.48 Credits（¥9.7/条）
- 发现太贵后才换 Seedance 1.5 Pro：21.34 Credits（¥2.35/条，便宜 4 倍）
- 合计浪费约 ¥10+

**关键事实**：manager 任务前已爬取 Evolink 完整模型清单（154 个模型，12+ 视频模型含定价），但"跑的时候一个都没对比，直接选了 seedance-2.0"。manager 自己承认："爬数据和用数据脱节了"。

这是 ClaudeTeam 闭环审计的**第 11 号漏洞：API 付费调用无预算边界**。现有十大修复全是被动检测型（心跳、状态、去重），拦不住 agent 主动花钱。

## 老板提出的修复方案

在 `manager_action_guard` 中增加 **API 付费预授权门禁**：

1. agent 调用付费 API 前，强制先列候选模型 → 对比价格 → 跑最便宜的 → 确认效果
2. 跳过对比直接跑贵的（Credits > 阈值），自动注入警告到 pane
3. 超过预算上限（如单任务 > ¥5）需老板确认

## 追问刘小排

1. 这个方案思路合理吗？1-10 打分
2. 如果很烂，烂在哪里？根本问题是什么？
3. 改进方法是什么？

注意：这是技术+产品双重问题——技术上要能拦截，产品上要让 agent 形成"花钱前先比价"的行为习惯而不是绕过门禁。
